Job Hunter

A desktop application that aggregates postings from seven applicant tracking systems, then scores each one against a candidate profile. Requirement extraction runs through an LLM; matching uses sentence-transformer embeddings against the extracted requirements rather than raw keyword overlap.

The interesting part is the filtering. Language requirements are the hard gate in this market, so the knockout detector defaults to deny on any mention of a language in a requirement context unless the posting explicitly softens it. Three earlier versions failed on phrasings like "fluent in English and German," which is how the default-deny posture got there. Scores are capped so that postings dense in matching vocabulary cannot outrank eligibility.
